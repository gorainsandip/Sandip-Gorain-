# Sago Store — সেটআপ গাইড

## ফাইল স্ট্রাকচার
```
website/
  index.html        → কাস্টমার-facing দোকান (প্রোডাক্ট দেখা, কার্ট, অর্ডার)
  admin.html         → অ্যাডমিন প্যানেল
  css/style.css      → সব স্টাইল
  js/firebase-config.js
  js/store.js        → index.html এর লজিক
  js/admin.js        → admin.html এর লজিক
  firestore.rules    → Firestore এর সিকিউরিটি রুলস (Firebase কনসোলে পেস্ট করতে হবে)
  storage.rules      → ছবি আপলোডের সিকিউরিটি রুলস
```

## Firebase কনসোলে যা যা করতে হবে (একবারই করলেই হবে)

প্রজেক্ট: **sago-ce761** — https://console.firebase.google.com/project/sago-ce761

### ১. Authentication চালু করুন
- বাম পাশের মেনু থেকে **Build → Authentication → Get started**
- **Sign-in method** ট্যাবে গিয়ে **Google** চালু (Enable) করুন
- এই Google Sign-in দিয়েই আপনি (`gorainsondip@gmail.com`) admin.html এ লগইন করবেন

### ২. Firestore Database তৈরি করুন
- **Build → Firestore Database → Create database**
- "production mode" সিলেক্ট করুন, কাছের একটা location দিন
- তৈরি হওয়ার পর **Rules** ট্যাবে গিয়ে এই রিপোজিটরির `firestore.rules` ফাইলের পুরো কনটেন্ট কপি করে পেস্ট করে **Publish** করুন

### ৩. Storage চালু করুন (প্রোডাক্টের ছবির জন্য)
- **Build → Storage → Get started**
- একই ভাবে **Rules** ট্যাবে `storage.rules` ফাইলের কনটেন্ট পেস্ট করে Publish করুন

### ৪. ওয়েবসাইট হোস্ট করুন
সবচেয়ে সহজ উপায় — Firebase Hosting (ফ্রি):
```bash
npm install -g firebase-tools
firebase login
cd website
firebase init hosting     # public directory হিসেবে বর্তমান ফোল্ডার (.) বেছে নিন
firebase deploy
```
এটা করলে একটা লিংক পাবেন যেমন `https://sago-ce761.web.app` — এটাই আপনার লাইভ দোকান।
অ্যাডমিন প্যানেলে ঢুকতে যাবেন `https://sago-ce761.web.app/admin.html`

(চাইলে Netlify, Vercel বা যেকোনো স্ট্যাটিক হোস্টিং এও আপলোড করা যাবে — এটা প্লেইন HTML/CSS/JS ফাইল।)

## কীভাবে কাজ করবে

**কাস্টমার (index.html):**
- প্রোডাক্ট গ্রিড থেকে ক্লিক করলে প্রোডাক্টের ভিতরে ঢুকে ছবি, বিবরণ, দাম দেখা যাবে
- প্লাস/মাইনাস দিয়ে কতটা নেবে ঠিক করে "কার্টে যোগ করুন"
- উপরে কার্ট বাটনে ক্লিক করলে যা যা নিয়েছে, মোট কত টাকা — সব দেখাবে
- "অর্ডার করতে যান" চাপলে নাম/ফোন/ঠিকানা দিয়ে "অর্ডার সাবমিট করুন" — অর্ডার সরাসরি Firestore এ চলে যাবে

**অ্যাডমিন (admin.html):**
- Google দিয়ে লগইন — শুধু `gorainsondip@gmail.com` (সুপার অ্যাডমিন) অথবা আপনার যোগ করা ইমেইল দিয়ে ঢোকা যাবে
- **প্রোডাক্ট ট্যাব**: নতুন প্রোডাক্ট অ্যাড, এডিট, ডিলিট — নাম ও বর্তমান দাম আবশ্যক, বাকি সব (ছাড়ের দাম, স্টক, ছবি, বিবরণ) ঐচ্ছিক
- **অর্ডার ট্যাব**: রিয়েল-টাইমে নতুন অর্ডার আসলেই **শব্দ (বিপ) বাজবে** এবং ব্রাউজার নোটিফিকেশন দেখাবে (প্রথমবার পেজ খুললে নোটিফিকেশন পারমিশন চাইবে, "Allow" দিতে হবে)। প্রতিটা অর্ডারে ক্লিক করলে বিস্তারিত দেখা যাবে ও স্ট্যাটাস (নতুন/কনফার্মড/পাঠানো হয়েছে/ডেলিভার/বাতিল) পরিবর্তন করা যাবে
- **অ্যাডমিন ম্যানেজ ট্যাব** (শুধু সুপার অ্যাডমিন দেখবেন): এখানে ইমেইল বসিয়ে নতুন অ্যাডমিন যোগ করা যাবে, আবার রিমুভ বাটনে ক্লিক করে বাদও দেওয়া যাবে

## ⚠️ একটা গুরুত্বপূর্ণ কথা — "অ্যাডমিন বানানো" নিয়ে
আপনি যাকে অ্যাডমিন বানাবেন, তাকে নতুন করে Firebase Auth অ্যাকাউন্ট বানিয়ে দেওয়া হয় না (এটার জন্য সার্ভার/Cloud Function লাগে, যা এই সেটআপে নেই)। এর বদলে সহজ ও নিরাপদ পদ্ধতি ব্যবহার করা হয়েছে:
- আপনি অ্যাডমিন প্যানেলে যে ইমেইলটা যোগ করবেন, সেই ইমেইল দিয়ে **নিজে** Google দিয়ে লগইন করলেই তার অ্যাক্সেস চলে আসবে
- অর্থাৎ যাকে অ্যাডমিন বানাতে চান, তার Gmail ঠিকানাটা "অ্যাডমিন ম্যানেজ" ট্যাবে বসিয়ে দিন — সে নিজের Gmail দিয়ে admin.html এ লগইন করলেই ঢুকে যাবে
- রিমুভ করলে সাথে সাথে তার অ্যাক্সেস চলে যাবে

আপনার (`gorainsondip@gmail.com`) সুপার অ্যাডমিন স্ট্যাটাস কোডে হার্ডকোড করা, এটা কখনো রিমুভ করা যাবে না।
